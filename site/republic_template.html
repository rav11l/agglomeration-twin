      Источники и способ расчёта

      У каждого слоя своя дата. Все 45 профилей строятся из одного набора исходных таблиц; HTML работает без подключения к сети.

      Методика доступности и сценариев

      Вес межрайонной связи — exp(−время/τ). Для каждого места назначения суммируется население 45 МО с такими весами, затем работники организаций этого назначения распределяются между потенциальными жителями. Доступность — сумма этих долей на одного жителя. Среднее время двух направлений используется в модели конкуренции, максимальное — для проверки порога доступности в обоих направлениях. Внутрирайонное время условно равно 10 минутам.

      Сценарий прибавляет условных работников к выбранным МО. Средний эффект взвешен по населению всех 45 МО. Вариант «По численности жителей» распределяет ровно 1 000 мест с округлением методом наибольших остатков. «Выравнивать доступность» — жадная эвристика: на каждом из десяти шагов выбирается размещение 100 мест, которое больше улучшает наименьший относительный эффект по 45 МО; при равенстве сравнивается средний эффект. Глобальный оптимум для 45 МО не заявляется.

      Модель не учитывает миграцию, изменение зарплат, профессиональное соответствие, стоимость строительства и ограничения транспортной системы. Сохранение массы распределённой занятости проверяет арифметику и не подтверждает соответствие фактическим трудовым поездкам.
